Public-interest / pile-on revision

  • Three new cases: Caroline Flack, Jason Arday and Raheem Sterling. The three original fact-check cases remain available.
  • Twenty-four coverage pieces in total. Two Sterling examples are historical headline reproductions, one an excerpt. Original live pages and complete context were unavailable; the reproduction links and limits are labelled.
  • Public value and pressure or humiliation receive separate ratings. Faithful, Mixed, Traitor and Unclear are player judgments, with no automatic moral answer key.
  • Five evidence checks award two points each. Editorial calls and a 40–600-character argument are retained in the round for discussion and receive no correctness score.
  • All 21 tests passed: backend, real-case binding and metadata, offline scoring, embedded-case parity, and credential protection. Tests use fake providers and incur no provider charges.
  • A complete browser round used all four verdict types, received 10/10 evidence points, and revealed the correct publishers, source links and written argument.
  • A live DeepSeek reply weighed public-interest value, amplification risk and source limits. The reply was spoken through ElevenLabs. Four distinct voices were verified in the preceding prototype; this revision made one new spoken-reply check.
  • Desktop rendering was inspected. The phone layout in this revision has not been exercised on a physical device.

This is a framework for examining an outlet’s contribution to a campaign. A story can add useful scrutiny and still use disproportionate treatment. Coverage stages and what was known at publication matter. Neither a later tragedy nor a complaint alone settles every earlier verdict. The packet does not establish every journalist’s private motive, actual reader feelings, or a causal explanation for a death.

Sharing and access

The game runs on this Mac’s loopback address. Public GitHub shares source code; it does not deploy a playable website. Each person downloading the code supplies their own DeepSeek and ElevenLabs keys and pays for their own provider use.

Real keys stay in private server settings outside the repository. The public example uses placeholders. Commit and push guards inspect staged files and Git history; checks against the locally held keys passed.

Save HTML downloads a standalone practice copy. The test browser blocks local-file URLs, so direct offline reopening is not confirmed for this revision. External native sharing to a recipient was not exercised; attach the downloaded HTML to share it.

Provider limits remain: 12 AI responses, 320 output tokens per response, 20-second timeout; 8 generated voice clips and 4,000 speech characters per session. Human listening, gameplay acceptance and independent editorial review remain open.
