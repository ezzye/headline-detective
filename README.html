Run the local game

  1. Install Node.js 22 or later from Node.js.
  2. Open a terminal in this repository folder and run:
npm run setup:hooks
npm start

Open http://127.0.0.1:9027/. No packages need to be installed. Without provider keys, the game uses labelled practice analysis and captions.

Add your own AI and voice settings

Copy .env.example to .env in the repository folder. Fill in your own DeepSeek and ElevenLabs keys and four distinct voice IDs. The example contains placeholders and public voice IDs.

The .env file is ignored by Git. Keys are used only by the local server. For a settings file outside the repository, start with:

HEADLINE_DETECTIVE_ENV_FILE=/absolute/path/private.env npm start

Existing environment settings also work. Each person who clones the game supplies their own provider access. DeepSeek keys · ElevenLabs keys · ElevenLabs plan and payment

Share safely

The public repository is ezzye/headline-detective. Share that link for the source. This does not publish a playable website; the game runs locally.

For offline play, share index.html itself. Its Save HTML and Share file controls create a portable copy. Live AI questions and ElevenLabs audio require the local server. These controls save this setup guide; attach the downloaded file if native sharing is unavailable.

npm test
npm run check:secrets

Tests use fake providers and incur no provider charges. Once installed, the local hooks check staged files before a commit and all local history before a push. The guard recognises common credential formats and available known keys; it cannot recognise every possible secret. Keep private settings and generated private files outside tracked source.

Play a public-interest round

Choose Caroline Flack, Jason Arday or Raheem Sterling. Compare the dated coverage, hear four analysts, and ask up to three questions. For each piece, rate public value and pressure or humiliation separately, then choose Faithful, Mixed, Traitor or Unclear.

Explain what the coverage contributes, what crosses the line, and why. The game distinguishes originating a frame, amplifying it and reporting criticism of it. A later tragedy does not decide every earlier judgment.

How to win

Five evidence checks earn two points each. Reach 8/10 to win. These checks test supported facts, chronology, public-interest arguments and uncertainty about motives. Your editorial verdicts and written argument are open to discussion and receive no automatic correctness mark. The three original fact-check cases retain their existing public-trust scoring.

What the evidence means

Six historical cases contain 24 coverage pieces, including two labelled headline reproductions in the Sterling case; one is an excerpt. Some pieces examine or challenge the campaign rather than originate it. Dates, genres, source versions and missing original context are stated.

AI players are simulated analysts, not publisher representatives. The cases do not establish how often an outlet is biased, every journalist’s private motive, reader feelings or a causal explanation for a death. Read the verification receipt for checks and remaining human review.

Public source does not grant rights to third-party reporting. Follow the linked publishers for the original stories.
