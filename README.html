Headline Detective

Read the timeline, examine an outlet’s campaign, hear a sourced editorial defence, then decide whether its coverage was proportionate.

Open gameVerification status

Six steps

  1. Welcome — choose a case and learn what its figures count.
  2. Timeline — follow documented events and the status of allegations.
  3. Scrutiny — use the same six criteria for each outlet.
  4. Hear — read or listen to a reviewed, first-person editorial defence written for the game.
  5. Judge — rate the coverage, give a verdict, suggest a proportionate count and answer five factual checks. These judgments are ungraded.
  6. Reveal — see the source identities, preserved judgments and five evidence-check results worth two points each; 8/10 wins.

Scrutiny criteria: public value, context, framing, care, consistency, and transparency. Questions are tied to supplied sources and identify what those sources cannot establish. Role-played defences are not statements from the actual publishers.

Caroline Flack · aggregate print-coverage analysis

The Guardian reports 99 print stories in The Sun among 387 stories across UK national newspapers during 14 August 2019–14 February 2020, a 185-date window. The count includes stories with “Caroline Flack” in the headline or body. Three Guardian journalists classified tone; the analysis is described as non-definitive and found mixed tone overall. The 99 are not established as 99 negative stories.

This case has no daily counts, peak day, full outlet roster, or item-level inventory in the game. Its example is a reported Sun online Valentine-card story; whether it appeared in print or belongs to the 99 is unknown. Arday counts distinct substantive written items from a selected inventory; Flack uses the Guardian’s aggregate print-story mention rule. Their methods are not directly comparable.

Run locally

  1. Install Node.js 22 or later.
  2. In a terminal opened in this folder, run:
npm start

Open http://127.0.0.1:9027/. No packages need installing. Without provider keys, the game offers reviewed text defences and labelled simulated practice replies.

Use your own provider keys

Live DeepSeek responses and optional ElevenLabs voices use your own accounts and provider billing. Copy .env.example to a private, ignored .env file, or keep settings outside the repository:

HEADLINE_DETECTIVE_ENV_FILE=/absolute/path/private.env npm start

Never share private configuration. The example file has placeholders. No provider keys or private config are included with the shared game; each player supplies their own access and pays their own usage.
